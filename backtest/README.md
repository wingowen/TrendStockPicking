# 突破趋势跟踪 · 回测机制

不再调用问财接口。全部行情取自东方财富公开日线接口，本地落 SQLite，回测与筛选共用同一份数据。

## 一、跑起来

```bash
cd /Users/wingo.wen/Documents/wencai/backtest

# 1) 抓数据（首次约 4-5 分钟，3036 只主板股）

# 4) 补面板辅助数据（行业 / 不复权收盘 / 另外两只指数）

```

```bash

```

它会全量重抓日线（只增量补会让复权因子不一致）、补行业与不复权价、重生成最近 30 个交易日的面板快照。

产物：`report.html`（报告）、`trades.csv`（逐笔明细 20707 行）、`summary.json`（指标）。

## 二、数据

| 项 | 说明 |
|---|---|
| 来源 | `push2his.eastmoney.com/api/qt/stock/kline/get`（日线，`fqt=2` 后复权） |
| 股票池 | 沪深主板（600/601/603/605/000/001/002/003），剔除当前名称含 ST/*ST/退 |
| 规模 | 3036 只，2990 只有足够历史；5,878,497 根日线，46 只无数据 |
| 区间 | 2018-01-02 → 2026-11-20；评估从 2020-01-01 起（前 70 根做暖机） |
| 基准 | 沪深300、上证指数、深证成指、创业板指（同源） |
| 辅助表 | `stocks.industry`（东财 f100 二级行业）、`bars_raw(code,date,close)`（近 120 交易日不复权收盘，仅面板展示用） |
| 表结构 | `stocks(code,name,market,list_date,mktcap)`、`bars(code,date,open,close,high,low,volume,amount)`，主键 `(code,date)` |

用后复权而不是前复权：前复权对上世纪上市的老股会产生负价（浦发银行 1999 年 -1.48），后复权全程为正，且除权日不会制造假突破。

## 三、面板叠加的三层判断

| 层 | 口径 | 用途 |
|---|---|---|
| 大盘闸门 | 上证指数 vs MA20/MA60 + 20/60 日动量；同时站上两线且 20 日动量为正 = 强，同时跌破两线 = 弱，其余 = 震荡 | 弱市里突破失败率显著上升，先决定「今天该不该动手」 |
| 板块趋势 | 成分股等权累乘成板块指数（≥5 只），四项各 25 分：站上 MA20、站上 MA60、20 日动量 >0、近 5 日资金净流入比 >0；≥75 强、≤25 弱 | 只用来避雷，不用来追强 |
| 回踩 | 突破后最低价触及突破位上方 2% 内、收盘不破位 = 回踩；之后收盘站上回踩前高点 = 回踩确认；回踩量 < 突破日量 = 缩量回踩 | 回踩确认是二次确认信号，比直接拉升更可靠 |

个股评分 = 回踩 35% + 量比 25% + 幅度 25% + 板块强度 15%（不含大盘，大盘单独当闸门）。

### 三层因子实测（新基准：不设结构止损 + 移动止盈 25% + 120 日）

`analyze_factors.py`，2020-01-01 起 21298 笔：

| 层 | 分组 | 笔数 | 单笔净期望 | 胜率 | 20 日前瞻 |
|---|---|---|---|---|---|
| 全部 | 原始信号 | 21298 | +1.14% | 38.9% | +0.45% |
| 大盘 | 强 | 12184 | **+2.22%** | 40.5% | +0.72% |
| 大盘 | 震荡 | 5385 | -0.79% | 35.5% | +0.18% |
| 大盘 | 弱 | 3729 | +0.38% | 38.3% | -0.08% |
| 板块 | 强（含资金流入） | 16260 | +1.13% | 39.0% | +0.51% |
| 板块 | 中性 | 3127 | +1.32% | 38.2% | +0.47% |
| 板块 | 弱 | 1766 | +0.71% | 39.0% | -0.36% |
| 板块评分 | 75（刚转强） | 3253 | **+2.10%** | 39.0% | +0.70% |
| 板块评分 | 100（四项全满） | 14661 | +1.05% | 39.0% | +0.50% |
| 板块评分 | 0（全面破位） | 727 | +0.81% | 37.8% | -0.79% |
| 资金 | 连续净流入 ≥3 日 | 7195 | +1.08% | 39.0% | **+0.81%** |
| 资金 | 当日无净流入 | 6509 | +0.78% | 37.3% | -0.01% |
| 回踩 | 确认后入场 | 1111 | -0.19% | 32.0% | -0.30% |

结论（基准换成宽止盈后）：

1. 紧止损掩盖了大量因子的真实效果：同样这批信号，单笔从 -0.55% 变成 +1.14%，20 日前瞻从 +0.45% 保持一致但分布完全不同；
2. **大盘仍然最有效**：强市 +2.22% vs 震荡 -0.79%，20 日前瞻弱市转负；
3. 板块「评分 75（刚转强）」+2.10% 明显好于 100 分 +1.05%，「弱」不再是最差（+0.71%），说明板块只值得当 75 分这一档的加分项 + 0 分避雷；
4. 板块资金流依然有领先性：连续 3 日净流入组 20 日前瞻 +0.81%，无净流入 -0.01%；
5. **回踩确认仍然拖收益**：等回踩确认再买 -0.19%，而同批信号信号日直接买 +7.94%（含事后选择偏差），说明确认会错过首段。

## 八、每日精选（面板顶部「今日最该关注」）

`rank_signals.py` 用信号当日可知信息给每只票算一个**排序分**，权重按 7 年分层的单笔期望校准
（不再用拍脑袋的权重，也不是“刚站稳/别追高”那套直觉——实测恰好相反）：

| 维度 | 赋分 | 依据（分层的单笔期望） |
|---|---|---|
| 大盘 | 强 +40 / 弱 +5 / 震荡 −20 | 强 +2.22% / 弱 +0.38% / 震荡 −0.79% |
| 板块评分 | 75 → +25 / 100 → +10 / 50 → +5 | 75 分 +2.10%、100 分只有 +1.05% |
| 连续净流入 | ≥3 日 +12 / 1–2 日 +6 | 与资金流方向同向 |
| 站稳天数 | 6–8 天 +15 / 5 天 +10 / 3–4 天 +5 | 6 天 +2.85%、7 天 +2.60%、8 天 +1.84% |
| 距突破位 | <5% +25 / 5–8% +12 / 8–12% 0 / >12% −25 | 3–5% +2.17% → >12% −2.58%（单调） |
| 量比 | <1.8 +10 / 1.8–1.9 +2 / ≥1.9 +6 | 1.65–1.8 最好 +1.61% |

按分档验证（21298 笔信号）：

| 分档 | 单笔期望 | 胜率 |
|---|---|---|
| 0–9 | −2.72% | 30.5% |
| 70–79 | +2.22% | 39.1% |
| 80–89 | +2.52% | 41.5% |
| 90–99 | +2.43% | 42.1% |
| 100–109 | +4.39% | 46.0% |
| 110–119 | +4.69% | 45.6% |

分数线扫描（当日最多取 3 只、3 仓）：

| 分数线 | 成交笔数 | 单笔期望 | 胜率 | 组合净值 | 最大回撤 |
|---|---|---|---|---|---|
| ≥80 | 1854 | +3.95% | 43.5% | +8.8% | −10.1% |
| ≥90 | 1667 | +4.55% | 44.2% | +38.2% | −8.9% |
| **≥95** | **1528** | **+4.71%** | **44.9%** | **+32.6%** | **−8.9%** |
| ≥100 | 1320 | +4.64% | 44.4% | +28.1% | −8.9% |
| ≥105 | 874 | +5.72% | 44.4% | +20.4% | −8.4% |

结论：**取 95 分线、每日最多 3 只**。弱市/震荡里常常一个都到不了 95（此时面板显示“今日优先观察”，
把前 3 名降级展示并标注“只观察”）——这是设计意图，不是故障。

两段式名单：**观察池**（突破日当天就进池，量比达标、未满 3 天，逐日跟踪；收盘跌破突破位即标红出池）+ **确认名单**（满 3 天且涨幅 ≥3%，进主表与精选）。页面顶部「新突破观察池」可勾选“只看今日突破 / 隐藏已破位”。

内嵌图表：主表和观察池的行点开后有「日K · 近60日 / 分时 · 实时」两个图。日K 用本地库 OHLCV（生成快照时按票嵌入 `klines`，不复权展示价，带 MA5/10/20、成交量、突破位虚线和突破日标记，滚轮缩放）；分时打开时通过 JSONP 实时拉东财 `trends2` 接口（当日 241 个分钟点 + 均价线 + 昨收基准，需联网，非交易时段显示最近交易日），可点「刷新」重拉。图表库为本地 `echarts.min.js`（离线可用）。

面板交互：表下方有 7 个独立过滤条件（信号日=今日新进名单 / 大盘非弱 / 板块强势或非弱 / 站稳天数 / 量比区间 / 回踩状态 / 排序分档），
可叠加；表头 7 列可点击排序（排序分、突破日、收盘、距突破位、站稳、量比、突破日成交额），再点一次反向。

回踩不进排序分：回测里“等回踩确认后再进场”单笔 −0.19%，还不如信号日直接买，所以回踩只在明细里作结构参考。

## 五、止损方案实测（`stop_sweep.py` → `stops.html`）

信号集固定，只换出场规则，2020-01-01 起 21298 笔，0.4% 往返成本，等权净值衡量规则本身：

| 方案 | 单笔净期望 | 胜率 | 结构止损占比 | 平均持仓 | 等权收益 | 等权最大回撤 |
|---|---|---|---|---|---|---|
| 纯持有 120 日（几乎不止损） | **+2.19%** | 42.5% | 0% | 116.7 | +21.7% | -34.6% |
| 不设止损 + 移动 25% | +1.14% | 38.9% | 0% | 85.5 | +6.4% | -39.8% |
| 不设止损 + 移动 18% | +0.44% | 36.2% | 0% | 60.6 | -0.4% | -40.3% |
| 当前口径：跌破突破位 | -0.55% | 24.8% | 58.2% | 21.6 | -42.9% | -54.9% |
| 跌破位下 3% 缓冲 | -0.35% | 30.1% | 42.0% | 28.7 | -26.5% | -46.5% |
| MA20 止损 | -0.86% | 28.2% | 0% | 14.7 | -79.2% | -80.2% |

结论：

1. **止损越紧越亏**。结构止损放在突破位附近正好落在噪声区，58% 的持仓被洗出去，平均亏 -6.90%；
   固定 -6/-8/-10% 硬止损、20/40/60 日时间止损、MA20/MA50 均线止损全部劣于原方案。
2. **收益全在右尾**，唯一有效的风控是放宽移动止盈（18%→25%→几乎不设），让赢家跑；
   代价是平均单笔亏损从 -6.9% 放大到 -15%~-17%，所以必须用仓位控制风险（风险预算式定仓），不能只靠止损。
3. 大盘闸门在新出场下依然有效：大盘非弱 +0.65%（15644 笔）vs 弱市 -0.16%（5654 笔）。
4. 分年度看不是只靠某一年：2021、2025 为正，2022、2024、2026 为负，说明还需要入场侧的过滤。

## 六、真实主力资金流的可得性（`flow_validate.py`）

- 东财 `fflow/daykline`（个股与板块）**历史固定只有 120 个交易日**（`lmt` 参数无效），最早 2026-05-27，
  因此 2020 年起的回测**无法**使用真实主力净流入。
- 代理口径（上涨日成交额记正、下跌日记负）与真实「主力净流入净占比」在 120 日重叠样本上：
  横截面相关系数均值 0.47（最差日 -0.02），逐笔符号一致率 67%（最新一日 91%）。→ 方向可用，幅度不可信。
- 面板只用到近 5 日，可以改吃真实主力净流入；回测继续用代理并注明这一偏差。
