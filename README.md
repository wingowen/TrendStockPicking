# TrendStockPicking · A 股突破趋势跟踪面板

主板突破选股 + 每日快照面板。数据来自东方财富公开行情接口，落本地 SQLite，不依赖商业数据源。

## 在线面板

GitHub Actions 每交易日 15:20（北京时间）自动重建：

- 面板：`https://wingowen.github.io/TrendStockPicking/breakout-panel.html`
- 规则卡：`https://wingowen.github.io/TrendStockPicking/rules.html`（右下角「回撤曲线」浮窗）

## 一句话结论（先看这里）

**这套信号在 2022 年之后没有可验证的选股超额了。** 同一池等权基准对照：2020–2021 每个信号的 20 日超额 +1.29%（按信号日聚类 t=+4.38），2022–2026 只剩 +0.06%（t=+0.29）。唯一还站得住的子集是「强市」里的信号：+0.63%/20 日（t=+3.88，n=7971）；震荡 −0.38%、弱 −1.25%（t=−3.79）。所以 v3 口径把「只在强市开仓」写成硬规则，其余时间空仓拿现金。

组合层 2022–2026 样本外 +19.3%（年化 +3.7%、回撤 −21.2%、Sharpe 0.34、86 笔），同期沪深300 −19.6%（回撤 −35.8%）。但 86 笔里前 3 笔贡献了全部盈利的 86%，随机填仓 30 次年化中位 +2.19%（5–95% −1.7%~+9.3%）——**优势主要来自「熊市不开仓」，不是选股**。

## 选股口径（v3 冻结版）

- 股票池：主板，剔除 ST / 科创 / 创业 / 北交所
- 突破位：信号日前 20 个交易日最高收盘价
- 量能：突破日成交量 / 前 5 日均量 ∈ 1.5–2.0
- 站稳：收盘在突破位上方满 3 个交易日后才可入场（突破日记为第 1 日），且累计涨幅 ≥3%
- 大盘闸门：上证 vs MA20/MA60 + 动量 + 量能 → 强 / 震荡 / 弱；**只有「强」允许开仓**
- 排序分 v3（只保留训练期稳定的 4 个因子）：强市 +、距突破位越近越好、站稳天数越多越好、量比 1.65–1.8 略优；权重在 `backtest/engine_v2.py` 里硬编码冻结，代码见 `V3_W / V3_MU / V3_SD`
- 入场：信号次日开盘买；高开 >9.5% 或低开 >3% 放弃；每日最多 3 只
- 出场：收盘从持仓峰值回撤 25%、或满 120 个交易日 → 次日开盘卖；**不设个股止损**（跌破突破位不砍，尾部靠仓位与净值闸门兜）
- 仓位：10 仓上限，每仓 10% 权益等额；不计整手时的碎股按 100 股向下取整，买不起就跳过
- 净值风控：相对近 252 个交易日峰值回撤 10% → 半仓；15% → 停止新开仓；权益回到阈值内自动恢复
- 空仓现金按年化 1.5% 计息
- 面板对应关系：`breakout-panel.html` 的持仓池是**信号跟踪**（同样的入场/出场/10 仓上限/仅强市，但不扣 0.4% 成本、不按 10% 等额定仓），浮盈会高于回测净值；「今日候选」在强市按排序分取前 3，**不设分数线**，非强市只列观察、标注不可开仓

## 回测基准（`backtest/spec_v3.json` 为唯一数字来源）

| 指标 | 全样本 2020-01→2026-11 | 样本外 2022-01→2026-11 |
|---|---|---|
| 成交笔数 | 135 | 86 |
| 累计 | +25.0% | +19.3% |
| 年化 | +3.32% | +3.72% |
| 最大回撤 | −27.3% | −21.2% |
| Sharpe | 0.30 | 0.34 |
| 单笔均值 | +3.15% | +3.07% |
| 单笔中位 | — | −2.79% |
| 胜率 | 45.2% | 45.3% |
| 平均仓位 | 44% | 33% |
| 同期沪深300 | — | −19.6%（回撤 −35.8%） |

稳健性（同口径重算）：随机填仓 30 次年化中位 +2.19%、5–95% 区间 −1.7%~+9.3%、为正比例 67%；年度 bootstrap 200 次年化中位 +2.0%、5–95% −0.9%~+4.3%。

容量是硬约束：平均持仓 86 天、10 仓 → 每年最多 28 笔，而同期信号约 2723 笔/年，**只能成交 1%**。这就是「单笔有梯度、组合没收益」的结构原因，不是参数没调好。

逐年（冻结分数、每年独立起跑）：2020 +19.3% / 2021 +12.6% / 2022 +13.9% / 2023 −7.9% / 2024 +9.6% / 2025 +17.8% / 2026 −10.6%。

## 参数纪律

- 出场参数（25%/120 日）在 5 个变体的样本外差异落在噪声内，**冻结，不再优化**；想改必须先有新的样本外证据。
- 排序分权重只在 2020–2021 上拟合，已冻结在代码常量里；改权重必须重跑 `backtest/run_v3.py` 并同步 `V3_W`。
- 任何新想法都要走同一套验收：训练期拟合 → 2022 年后冻结验证 → 随机填仓区间 → 年度 bootstrap。只有单点数字变好、区间没变好，视为没改进。

## 回归测试门禁

`tests/` 现在是 37 例，分成两层，任何一层挂了 `run_daily.sh` 会直接中止：

- 信号层 `test_strategy.py`（27 例）：首次突破只算一次、站稳天数、量比区间、跳空 ±3%/9.5% 边界、TTL 缓存、面板信号与回测对齐。
- 引擎层 `test_engine_v2.py`（10 例）：买不起一手要计数跳过、并发仓位上限硬生效、5 万/10 仓等额定仓、**定仓只用昨日收盘权益（无未来函数）**、两次跑结果逐点相同、深回撤后闸门能恢复而不是永久锁死、排序分单调、单笔统计只算成交、面板与引擎冻结系数一致、`V3_SPEC` 不被偷改。

## 本地跑

```bash
.venv-bt/bin/python -m pytest tests/ -q            # 信号层 + 引擎层回归测试
.venv-bt/bin/python backtest/run_v3.py            # 重算 v3 官方数字（写 spec_v3.json / spec_v3.html）
./run_daily.sh                                    # 15:35 后：回归测试 + 全量抓数 + 重建面板
python3 build_panel_from_db.py --days 30 --intraday   # 盘中预览
python3 backtest/export_equity.py                 # 重算规则页净值/回撤
```

WSL 每日脚本用的是独立 `.venv`，启用同样门禁前需先 `.venv/bin/pip install pytest`。

## 数据与部署

抓数和构建跑在国内网络的 WSL 机器上：`server_daily.sh` 每日全量重抓东财 → 写本地 SQLite → 生成面板与净值 JS → force-push 到 `data` 分支。`.github/workflows/deploy.yml` 在收到 `data` 分支推送后只做静态打包与 Pages 部署，不抓数据（海外 IP 拿不到东财）。手动重新部署用 `workflow_dispatch`。

`ci_build.sh` 是早期 CI 方案，现已无人调用，保留仅作参考。

## 换方向时的现状（2026-11-21）

突破信号 2022 年后失效，另开的横截面方向（月末排序、持有期不交易）已经跑完，详见 `backtest/README.md` 第九·补节与
`backtest/alt_report.html`。三句话：

- **因子层站得住**：8 个因子在 20 日与 60 日两个标签上符号全一致，三折 IC 0.084 / 0.109 / 0.101。
- **组合层只留下宽度**：30 仓季调样本外 +37.0%，10 仓月调 −1.7%（成本 3.7%/年吃光 IC 0.10 的毛边）；所有变体样本外 t<1。
- **交叉验证的最硬产出是一条排除规则**：combo 最低 20% 分位里的突破信号，20 日超额 −0.72%（聚类 t=−2.21）；
  「只做高分档」在随机对照下无法区分，所以只把低分档当剔除条件，把高分档当参考。

同时翻出一个容量问题：只保留「≥250 根 K 线 + 20 日均额 ≥ 5000 万」的可成交池，v3 本体样本外从 +19.3% 掉到 +1.3%
——说明收益对次新/低流动性票有依赖，实盘容量要按成交额分层再核。

## 已知局限（写在明面上，不当成秘密）

1. **生存者偏差**：股票池只含当前仍在市的主板股票，已退市/被 ST 的没进样本，回测收益偏乐观。
2. **板块资金流**：历史真值只有 120 天，回测用代理，代理与真值横截面相关 0.47；v3 已把该因子从排序分剔除，但规则卡里的「近 5 日主力净流入 > 0」仍只是展示项。
3. **整手价格**：用「折回当前不复权尺度」的价格估整手，proxy 会低估历史真实价（差额＝入场至今累计分红，通常 <30%）。
4. **样本太小**：样本外 86 笔，单笔标准差 24.6%，任何一年的结论都可能是运气。
